Demonstração automática da WedTech

Esta página usa o sistema de verdade, sozinha: abre o site, entra como lojista e como consultor, vende no caixa e no Mercado Livre, abre um chamado, faz uma cotação com contrato, aceita como cliente e muda o plano de uma loja. Cada etapa aparece explicada no topo, com ✓ quando funciona.

⚠ Ela cria dados de verdade no sistema (pedidos, chamado, cotação e uma loja nova). Se quiser voltar ao estado de antes, faça uma cópia do database.sqlite antes de começar.

  1. Deixe o iniciar-tudo.bat rodando.
  2. Aperte F11 para tela cheia.
  3. Comece a gravar a tela (Clipchamp, OBS ou Windows + Alt + R).
  4. Clique em Começar: há uma contagem de 3 segundos.

⏸ Demonstração pausada

A janela ficou minimizada ou escondida atrás de outra, e o navegador deixa a página em câmera lenta. Assim que ela voltar a aparecer, a demonstração continua de onde parou.
